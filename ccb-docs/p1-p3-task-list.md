## 单 Agent 执行方式

每个阶段拆成独立任务执行：

1. 先读该任务涉及的现状和测试。
2. 写失败测试或明确可验证的验收检查。
3. 实现一个任务的最小闭环。
4. 运行聚焦测试。
5. 汇报结果后停止。
6. 用户确认后进入下一任务。
