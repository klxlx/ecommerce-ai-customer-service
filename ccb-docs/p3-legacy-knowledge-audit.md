# 旧 Markdown 知识审计

## 审计结论

本轮仅审计 `data/knowledge/manifest.json` 中登记的 8 份旧 Markdown
资料，不直接清空历史文件。该清单中的商品资料和政策资料均缺少可核验的
正式来源，因此统一标记为 `legacy`，并继续保留原始文件与校验和用于追溯。

## 处理规则

- 旧 Markdown 不再作为正式知识来源。
- 旧 Markdown 不参与正式检索和向量索引。
- 商品与交易规则以 `电商知识库文档` 中的 10 份正式 PDF 为准。
- 后续如需恢复某份旧资料，必须先补充来源、有效期和人工复核记录。
- 删除操作仅允许针对已确认重复、过时或来源不严谨的内容执行。

## 当前状态

8 份旧资料已停用，清单状态为 `legacy`。原始文件仍可通过清单中的 URI
和 SHA-256 校验和定位与核验。
