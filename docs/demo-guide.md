# 演示指南

启动后访问 `http://127.0.0.1:8000`，使用演示账号登录（`customer` / `password123`）。

本地启动请使用 `python -m scripts.serve --host 127.0.0.1 --port 8000`（不要用
`uvicorn app.main:app` 直接启动；Windows 上 Uvicorn 默认的 Proactor 事件循环与异步
psycopg 不兼容）。该启动方式不需要 `--reload`。Docker Compose 方式不受影响。

## 顾客端演示场景

1. **招呼寒暄**：输入「你好」，得到固定问候，无需调用模型。
2. **商品咨询**：输入「声动 Pro 无线蓝牙耳机怎么使用」，返回参数/用法并附来源溯源。
3. **规则咨询**：输入「退换货政策是什么」，返回退换货规则并附来源。
4. **价格库存**：输入「蓝牙耳机多少钱」，返回实时价格与库存（来自 `products` 表）。
5. **订单查询**：输入「查询订单 ORD-20261117-0001 的物流」，返回订单状态与物流轨迹。
6. **越权订单**：登录后查询不属于自己的订单号，返回「未查询到该订单」，不泄露存在性。
7. **闲聊管控**：连续闲聊两轮后，第三轮被引导回业务。
8. **转人工**：输入「转人工」，生成人工工单并提示已转接。

## 管理端演示场景

1. 使用 `admin` / `password123` 登录，进入 `/admin`。
2. **工单队列**：按「待处理 / 处理中 / 已解决」过滤工单。
3. **工单详情**：查看需求摘要、槽位信息、最近会话、检索与工具证据。
4. **状态流转**：将工单标记为「处理中」或「已解决」。

## 数据实时性演示

在 PostgreSQL 中直接修改某商品的价格或库存：

```sql
UPDATE products SET price = 199.00, stock = 5 WHERE sku = 'EB-PRO';
```

再次向客服询问该商品价格，回答即时反映新值，无需重新索引。
